# 누띠 강아지 사진 놀이터

강아지 사진을 AI로 변환해 주는 서비스의 **와이어프레임 스펙 저장소**입니다.
구현 코드는 아직 없고, 기획·설계 문서만 담고 있습니다.

- 스펙 문서: [`docs/wireframe-spec-v0.5.html`](docs/wireframe-spec-v0.5.html) — 브라우저로 열어서 보세요
- 버전: v0.5 · 기준일 2026-08-03
- 구성: 11 plates (사용자 10 / 운영 1) · 결정 8건 · 열린 질문 6건

## 이 서비스의 위치

본체는 **nutti.co.kr 카페24 쇼핑몰**이고, 놀이터는 그것을 가리키는 **홍보 자산 중 하나**입니다.
SNS(@nutti_official), 간식 계산기와 병렬 관계이며 순서가 있는 깔때기가 아닙니다.

```
SNS · @nutti_official     간식 계산기(배포됨)      사진 놀이터(신규)
          \                     |                      /
           \                    |                     /
            → → →  nutti.co.kr · 카페24 쇼핑몰  ← ← ←
```

자체 수익 사업이 아니므로 **생성 원가는 매출로 회수할 대상이 아니라 광고비**입니다.
북극성 지표는 쇼핑몰 유입 기여 + **공유율**(이 자산만의 고유 강점 — 결과물이 사용자 손으로 퍼짐).

## 범위

**포함** — 강아지 전용 · 크레딧 무상(행동 보상형) · 결과물에 누띠 서명 · 기존 계산기 연결 · 단일 페이지 카탈로그 · 무료 체험 1장

**제외** — 크레딧 판매 · 고양이 · 스타일 검색 · 굿즈 커머스

## 핵심 플로우 (탭 4번)

```
랜딩 → 스타일 선택 → 사진 업로드 → 생성(20–40초) → 결과(변형 4장 + 서명)
                                                        ├─ 공유
                                                        ├─ 쇼핑몰
                                                        └─ 계산기(견종 프리필)
```

결제 단계가 사라진 자리에 **세 갈래 출구**가 들어옵니다. 업로드는 스타일 선택 *뒤에* 두고,
같은 사진 하나로 생성과 추천을 모두 처리합니다(재업로드 요구 시 대부분 이탈).

## 기술 제약 · 연동

카페24 스마트디자인은 HTML/CSS/JS 편집만 허용하고 **서버 코드를 올릴 수 없습니다.**
AI 생성은 API 키 은닉·작업 큐·저장소가 필요하므로 별도 백엔드가 필수이고,
따라서 **서브도메인**(`play.nutti.co.kr` 형태)에 두고 카페24 API로 묶습니다.

- **Admin API** — OAuth 2.0 인증 후 주문·회원 조회 → 구매 인증 시 크레딧 자동 지급 (W-10의 핵심 배선)
- **회원 연동** — 쇼핑몰 계정으로 로그인시켜 별도 회원 DB를 만들지 않음
- **계산기** — 손대지 않음. URL 파라미터를 읽어 프리필하는 코드 한 조각만 추가
- ⚠️ **토큰 갱신** — 카페24 토큰은 짧은 주기로 만료. 갱신이 끊기면 크레딧 지급이 **조용히** 멈추므로 실패 알림 필수

## 크레딧 (판매하지 않음)

| 획득 경로 | 크레딧 | 방식 |
|---|---|---|
| 누띠 주문하기 | +20 | 주문 1건당 · Admin API 자동 확인 |
| 쇼핑몰 계정 연동 | +3 | 최초 1회 |
| 인스타 팔로우 | +2 | 자율 지급 (API로 검증 불가, 검증하지 않음) |

v0.2에서 크레딧은 **수익원**이자 결제 장벽이었지만, 지금은 **미끼**입니다 — 크레딧을 원할수록
쇼핑몰과 인스타로 갑니다. 같은 UI 요소의 역할이 정반대로 뒤집혔습니다.

## 설계 근거 (경쟁 서비스 5종 리서치)

Pawtograph · PixPawAI · Pawcaso · DreamPets · EaseMate를 훑어 얻은 결론:

1. **3단계에서 벗어나지 않는다** — 업로드 → 스타일 → 결과. 편집 툴바 없음
2. **스타일 카드 = 결과물 이미지** — 카드 면적의 80% 이상이 적용 예시
3. **개수 경쟁에서 빠진다** — 250개와 겨루지 않고 «잘 되는 것만» 200 미만으로
4. **커스텀 프롬프트는 숨긴다** — 전면 노출은 학습곡선이 약점. 별도 진입점(W-08)으로 분리
5. **워터마크 불만에는 조건이 있다** — 반발의 핵심은 «돈 내야 지워준다». 전부 무료면 통과
6. **"내 강아지"가 핵심 가치** — 무늬·표정 보존. before/after 비교가 그 약속의 증명

## P0 엣지 케이스

- 생성 실패 → 크레딧 자동 반환, 원본 유지
- 타임아웃(60초) → 백그라운드 전환 + 완료 알림
- 크레딧 부족 → 인라인 오버레이, 주문 보상이 최상단
- **카페24 토큰 만료** → 관리자 알림 필수 (조용한 실패가 최대 급소)
- **주문 보상 후 주문 취소** → 회수 정책 미정 시 +20 반복 어뷰징 가능
- **사람 얼굴 포함 사진** → 초상권·정책 검토 필요
- 부적절한 커스텀 프롬프트 → 입력 필터 + 생성 후 안전 필터 2중

전체 표(P1 포함)는 스펙 문서의 «상태 · 엣지 케이스» 섹션 참고.
