# 웹폰트 출처와 라이선스

이 폴더의 폰트는 저희가 만든 것이 아니라 **제3자의 무료 배포 폰트**입니다.
자가 호스팅하는 이유는 `src/index.css` 의 웹폰트 주석에 적어 뒀습니다.

| 파일 | 서체 | 저작권자 | 공식 배포처 |
| --- | --- | --- | --- |
| `S-CoreDream-4Regular.woff2`<br>`S-CoreDream-6Bold.woff2`<br>`S-CoreDream-7ExtraBold.woff2` | 에스코어드림 (S-CoreDream) | 에스코어 주식회사 | https://s-core.co.kr/company/font/ |
| `Cafe24Ohsquare.woff2` | 카페24 아네모네 오스퀘어 (Cafe24 Ohsquare) | 심플렉스인터넷(카페24) | https://fonts.cafe24.com/ |

둘 다 **개인·기업 상업적 이용과 웹폰트 임베딩을 허용**하되 **폰트 파일 자체의
판매·재배포는 금지**합니다. 이 저장소는 서비스 렌더링 목적의 임베딩이라 허용
범위 안입니다. 정확한 조건은 위 공식 배포처의 라이선스 전문이 기준이며,
아래 요약은 참고용입니다.

## 파일에 손댄 내역

원본은 `.woff`(에스코어드림) / `.woff2`(오스퀘어)로 받았고, 에스코어드림 3벌만
**woff2 로 재압축**했습니다(345KB → 234KB 등). 글리프는 건드리지 않았습니다 —
서브셋을 뜨지 않은 것은 의도적입니다. 사용자가 입력하는 강아지 이름에 어떤
음절이 올지 알 수 없어서 완성형 한글 11,172자를 전부 남겨 뒀습니다.

받아 온 곳은 쇼핑몰이 쓰는 카페24 CDN 이지만, 그건 파일 취득 경로일 뿐이고
서비스는 이 폴더의 사본을 서빙합니다.

## 굵기 주의

에스코어드림의 굵기 이름은 CSS `font-weight` 와 어긋납니다.
**6Bold = 600, 7ExtraBold = 700** 입니다. 파일명만 보고 700 에 `6Bold` 를
매달지 마세요.
