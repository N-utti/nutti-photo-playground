# W-01 히어로 비교 슬라이더 이미지

`src/screens/W01Landing.tsx` 의 `HERO_BEFORE`·`HERO_AFTER` 가 가리키는 두 파일입니다.
이 화면의 임무는 «내 애가 유지된다»를 첫 3초에 증명하는 것이라(#p01 노트1) 여기 두
장은 장식이 아니라 **증거**입니다 — 반드시 **같은 강아지**의 원본/변환 한 쌍이어야
합니다. 다른 개 두 마리를 나란히 두면 이 화면은 자기가 증명하려던 것의 반례가 됩니다.

| 파일 | 크기 | 무엇 |
| --- | --- | --- |
| `before.webp` | 1200×800 | 나무 데크 위에 엎드린 흰 강아지 사진 (연두 목줄) |
| `after.webp` | 1200×800 | 같은 강아지를 피규어로 만들어 «KONG-I» 패키지와 함께 책상에 둔 생성 결과 |

둘 다 **3:2** 입니다. 히어로 프레임이 4:3 이고 `object-cover` 라 좌우가 깎이는데,
비가 서로 다르면 한 장만 더 깎여 두 사진의 눈높이가 어긋납니다. 바꿀 때도 이 비를
서로 맞추세요.

## `before.webp` — 원본 사진

Pixabay ID **1903313** 입니다. 사용자가 2026-09-01 에 전달했고, 받은 파일명이
`3194556-puppy-1903313_1920.jpg` 로 Pixabay 다운로드 규약(`{슬러그}-{id}_{폭}.jpg`)
그대로입니다. Pixabay Content License 는 **상업 이용 가능·출처 표기 불요**입니다.

라이선스 페이지를 브라우저로 직접 확인하려 했으나 Pixabay 가 Cloudflare 봇 검증으로
막습니다(2회 시도 후 중단). 근거는 파일명 규약과 사용자 확인입니다.

## `after.webp` — 변환 결과

누띠 자사 생성물입니다(원본 파일명 `nutti-e5bab88d-f1f3-42ef-a3e2-176d4cf3eb22.jpg`,
우하단에 «Nutti» 워터마크). **위 `before.webp` 를 입력으로 만든 결과**라 둘이 같은
강아지입니다 — 연두 목줄과 검은 버클까지 이어집니다.

## 가공

둘 다 원본이 1920×1280 이고, **1200×800 WebP 로 축소·재인코딩**만 했습니다
(Lanczos, quality 82/85). 크롭·색보정은 없습니다. 히어로 프레임이 CSS 기준 약
546×410 이라 2배 DPR 에서도 1200 이면 충분하고, 원본 그대로면 454KB + 243KB 를
첫 화면에 얹게 됩니다(지금은 53KB + 90KB).

## 과거 이력 — 왜 한 번 갈아엎었는지

처음(2026-09-01 오전) 들어왔던 쌍은 **퍼그** 사진과 그 애의 «KONGI» 피규어였는데
통째로 뺐습니다. 원본이 `studio22comua`/Getty Images/iStockphoto **유료 스톡**이었기
때문입니다 — The Guardian 기사 «How dogs capture your heart» 경유로 출처를 찾았고,
같은 사진인지는 눈이 아니라 원본을 받아 픽셀로 대조해 확정했습니다(평균 오차
1.4~2.0/255 = 재압축 노이즈 범위).

여기서 배울 것은 **파생물도 같이 걸린다**는 점입니다. 피규어 이미지는 그 스톡
사진을 입력으로 만든 2차적 저작물이라, «원본만 무료 사진으로 갈아 끼우기»가
성립하지 않았습니다. 누띠는 입력 사진에서 결과를 만드는 제품이라 이 구조가
계속 반복됩니다 — **원본과 결과는 항상 쌍으로** 교체하세요.
