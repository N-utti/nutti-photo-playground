## 개요

이번 개선은 누띠 사진 놀이터의 핵심 여정인 **사진 업로드 → 스타일 선택 → 결과 생성**을 첫 방문자도 빠르게 이해하고, 다음 행동을 확신 있게 수행하도록 만드는 데 집중했습니다. 기존의 따뜻한 누띠 브랜드 컬러와 서체는 유지하면서, 랜딩의 제품 가치 전달, 스타일 카드의 선택성, 업로드 단계의 안내, 하단 내비게이션의 명료도를 높였습니다.

| 개선 축 | 문제 인식 | 반영 결과 |
| --- | --- | --- |
| 첫 방문 이해 | 제품의 사용 순서와 before/after 상호작용이 빠르게 읽히지 않았습니다. | 랜딩에 제품 식별자, 3단계 흐름, 비교 슬라이더 안내, 강화된 CTA를 추가했습니다. |
| 스타일 탐색 | 카드의 비용·선택 가능성이 약하고 그리드 진입 시 맥락이 부족했습니다. | 카탈로그 도입부, 스타일 수, 이미지 위 비용 배지, 선택 화살표, 카드 상태 피드백을 적용했습니다. |
| 업로드 전환 | 파일 조건과 사진 품질 안내가 행동과 분리되어 있었습니다. | `STEP 01`, 예상 시간, 파일 형식, 대형 업로드 영역, 촬영 팁을 한 흐름으로 재배치했습니다. |
| 전역 탐색 | 하단 탭이 콘텐츠와 경계 없이 붙어 있었습니다. | 떠 있는 반투명 내비게이션과 활성 탭 배경을 적용해 현재 위치와 전환 가능성을 높였습니다. |
| 접근성·모션 | 인터랙션의 일관된 피드백과 모션 감소 설정 대응이 부족했습니다. | 키보드 포커스 규칙을 유지하고, 짧은 누름 피드백과 `prefers-reduced-motion` 대응을 추가했습니다. |

## 구현 상세

### 랜딩 화면

랜딩은 브랜드 식별자와 큰 제목을 통해 서비스의 목적을 먼저 전달하고, 비교 슬라이더에는 `원본`, `변환`, `좌우로 밀어 비교해 보세요`라는 안내를 함께 제공하도록 개선했습니다. CTA는 그림자와 짧은 이동 피드백을 사용해 주 행동으로 인식되도록 했으며, 바로 아래에 `사진 → 스타일 → 완성`의 3단계 미리보기를 배치했습니다. 가입 불필요·무료·강아지 전용이라는 기존의 마찰 제거 메시지는 유지했습니다.

### 스타일 카탈로그와 상세 시트

카탈로그 상단에 `STYLE CATALOG` 문구, 선택 안내, 총 스타일 수를 추가해 68개 카드 그리드로 진입하기 전에 탐색 목적을 설명합니다. 카드에는 이미지 영역의 크레딧 배지, 하단의 제목, 진행 화살표, 호버·포커스 상태를 적용했습니다. 스타일 상세 시트는 예시 영역, 스타일명, 비용, 적합도 태그, CTA의 순서를 더 선명하게 정리하고 캐러셀 지시자를 개선했습니다.

### 사진 업로드

사진 업로드는 파일 선택이라는 핵심 행동을 더 크게 드러내고, 지원 형식과 용량 제한을 클릭 이전에 안내합니다. 사용자는 저장된 강아지 재사용 여부를 확인한 뒤, 밝은 조명·한 마리·또렷한 얼굴 같은 사진 품질 조건을 짧은 칩 형태로 읽을 수 있습니다. 업로드 완료 뒤의 경고, 다른 사진 선택, 크레딧 반환 고지는 기존 정책을 그대로 보존했습니다.

## 알려진 제약 및 다음 우선순위

현재 목 데이터가 제공하는 일부 스타일 썸네일과 예시 이미지가 중립색 자리표시자이므로, 디자인 개선만으로는 스타일 결과물의 감성적 설득력을 완전히 대체할 수 없습니다. 실제 생성 결과 예시 또는 스타일별 대표 이미지를 연결하면 이번에 강화한 카드, 캐러셀, 랜딩 비교 슬라이더의 효과가 가장 크게 나타납니다. 다음 단계에서는 실제 스타일 자산을 우선 보강하고, 결과 화면에서 공유 이미지 저장과 쇼핑몰·계산기 이동의 전환 데이터를 확인하는 것을 권장합니다.
