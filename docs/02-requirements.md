# 02. 요구사항 명세 (FR / NFR)

> 기준: wireframe-spec v0.5 / cebb865

## 0. 표기 규약

- **FR ID**: `FR-<화면코드>-<순번>` (화면코드는 W-01~W-11, 엣지는 `EDGE`).
- **우선순위**: P0(필수) / P1(중요) / P2(선택).
- **출처**: 스펙 앵커(`#p01`~`#p11`, `#arch`, `#states` 등) 또는 결정 카드(`07-decisions.md#Qn`).
- **전역 컴포넌트**: 크레딧 잔액 배지(앱바)와 하단 탭바(스타일/만들기/보관함/누띠샵)는 여러 화면에 반복 등장하므로 최초 정의 화면(W-02)에서 1회만 FR로 기술한다. 다른 화면 표에서는 "전역 요소, FR-W02-07/08 참조"로 표기해 화면 요소 목록에서 누락되지 않게 한다.

## 4. 커버리지 검증

12개 화면(W-01~W-11 + 신설 W-12)의 와이어프레임 UI 요소·노트와 엣지 케이스 13건 전체가 위 표의 FR-xx / NFR-xx로 매핑되었다. 예외는 1건뿐이며 명시적으로 기록했다: **FR-W05-04(완료 알림)는 MVP 제외, 근거 `07-decisions.md#Q7`.**

전역 컴포넌트(크레딧 배지, 하단 탭바)는 각 화면에 반복 등장하지만 FR-W02-07/08에서 1회만 정의하고 다른 화면에서는 참조로 표기해 중복 없이 빈칸도 없게 했다(예: W-09 탭바 행).

출처가 없는 FR/NFR은 0건이다. 스펙 공백을 메우는 설계 결정은 전부 [07-decisions.md](07-decisions.md)의 ADR-lite 또는 관련 문서 절(04-erd·06-architecture)을 출처로 가리킨다.
