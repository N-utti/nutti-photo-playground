# UI·UX 현황 점검 메모

## 랜딩 화면 (2026-08-12)

- 데스크톱 첫 화면은 좌측 헤드라인과 CTA, 우측 before/after 비교 영역의 2열 구조다.
- 브랜드 색상은 따뜻한 아이보리 배경, 진한 갈색 텍스트, 올리브 계열 CTA로 구성되어 누띠 브랜드와 일관된다.
- 히어로 비교 영역은 현재 자리표시자 SVG를 사용한다. 제품 가치인 ‘원본 강아지의 특징 보존’을 실제 사진으로 증명하지 못한다.
- 하단 인기 스타일 카드도 API 목 데이터의 중립색 자리표시자가 우세해 시각적 기대감을 만들지 못한다.
- 상단 내비게이션은 데스크톱에서 ‘스타일’과 로그인만 제공하고, 제품의 핵심 여정(사진 업로드)을 다시 시작할 수 있는 보조 동선은 헤더에 없다.
- CTA 카피와 ‘가입 없이 · 전부 무료 · 강아지 전용’ 마찰 제거 문구는 명확하며, 개선 시 반드시 유지한다.
- 2열 히어로 비례와 대형 디스플레이 제목의 대비는 적절하다. 이후 개선은 실사진/생성 예시, 더 분명한 신뢰 신호, 결과 화면까지의 진행 예고에 집중한다.

## 스타일 카탈로그 (2026-08-12)

카탈로그는 상단의 크레딧·로그인, 가로 스크롤 가능한 카테고리 앵커, 모바일 2열·데스크톱 4열 카드로 정보 구조가 명확하다. 하단 고정 탭바도 주요 화면으로의 복귀 경로를 유지한다. 그러나 목 데이터의 중립색 SVG 썸네일과 ‘인기 스타일 N’ 같은 임시 명칭이 카드 기반 선택 경험의 핵심인 결과 기대감을 거의 전달하지 못한다. 특히 네 개 이상의 카드가 동시에 보이는 데스크톱 화면에서 카드 경계와 정보 밀도가 약해 탐색보다 목록 읽기처럼 느껴진다. 구현 개선은 API 데이터와 호환되는 범위에서 카드의 이미지 오버레이, 비용 배지, 선택 affordance, 섹션 소개 문구, 집중된 추천 지점을 추가하고, 실제 스타일 자산을 받을 때 즉시 풍부해지도록 폴백 상태도 브랜드화한다.

## 개선 후 랜딩 검증 (2026-08-12)

개선된 랜딩은 상단의 작은 제품 식별자, 더 분명한 CTA, `사진 → 스타일 → 완성`의 3단계 예고를 추가해 첫 방문자가 수행할 일을 더 빨리 파악하게 한다. 비교 슬라이더에는 원본·변환 상태와 드래그 안내가 분리되어 보이며, 그 아래 CTA와 무료·가입 불필요 안내가 한 묶음으로 유지된다. 현재 데이터가 제공하는 자리표시자 이미지의 한계는 남아 있으나, 카드의 반응·정보 영역과 계층은 실제 스타일 자산이 연결되었을 때 자연스럽게 강화되도록 설계했다.

## 개선 후 카탈로그 검증 (2026-08-12)

카탈로그 상단은 `STYLE CATALOG` 식별자, 선택 안내, 전체 스타일 수를 함께 보여 주어 이전의 곧바로 시작되는 그리드보다 맥락을 빠르게 제공한다. 각 카드에는 크레딧 비용을 이미지 영역에 분리해 표시하고 이름과 진행 화살표를 하단에 배치해 ‘미리 보기 → 상세 확인’ 행동을 명확히 했다. 하단 탐색은 화면 가장자리에 붙은 바 대신 떠 있는 반투명 컨테이너가 되어 콘텐츠와 구분되며, 활성 항목의 배경 강조도 정상적으로 표시된다.

## 개선 후 업로드 검증 (2026-08-12)

업로드 화면은 상단 맥락 카드로 ‘사진 먼저, 스타일은 나중에’라는 비선형 진입 경로를 설명하고, `STEP 01`·소요 시간·파일 형식 조건을 선택 행동 바로 앞에 배치한다. 큰 업로드 영역은 작은 화면에서도 한 번에 인지되며, 저장된 강아지 재사용과 촬영 팁의 우선순위도 자연스럽게 이어진다. 사진을 실제로 선택한 뒤의 확인 화면에는 기존의 경고·크레딧 반환 안내가 남아 있어, 미관을 높이면서도 신뢰 정보는 줄이지 않았다.

## 개선 후 스타일 상세 검증 (2026-08-12)

상세 화면은 카탈로그 위에서 시트로 열려 탐색 맥락을 유지한다. 큰 예시 영역, `STYLE PREVIEW` 표식, 분리된 크레딧 배지, 적합도 태그, 강조된 만들기 CTA가 순서대로 배치되어 사용자가 선택 근거와 비용을 확인한 후 다음 단계로 이동할 수 있다. 예시 데이터가 현재 중립색 자리표시자여서 이미지의 설득력은 제한되지만, 캐러셀과 점 표시의 구조 및 시트 대비는 실제 결과 이미지가 연동되면 즉시 활용 가능하다.
