## 6. 북극성 지표

목적이 매출이 아닌 "쇼핑몰(본체) 기여"이므로, 두 지표 모두 최종적으로 본체 유입/확산에 수렴한다. 출처: `wireframe-spec-v0.5.html#goal`

| 지표 | 정의 | 측정 방법 | 기준선 |
|---|---|---|---|
| 쇼핑몰 유입 기여 | 놀이터에서 쇼핑몰(nutti.co.kr)·계산기(calculator.html)로 이어지는 클릭 및 그 결과 세션 | GA4 이벤트(`shop_exit_click`, `calculator_exit_click`) + 아웃바운드 링크 UTM | **[Q1 GA 실측 대기]** — 계산기 기존 GA4 데이터에서 월 유입·쇼핑몰 전환율 실측 필요(사용자 액션). 실측 전까지 목표치는 플레이스홀더 |
| 공유율 | 결과 화면(W-06) 도달자 중 인스타 공유 버튼을 누른 비율 | `metric_event`(내부, 결과화면 도달 count / 공유 클릭 count) + GA4 이벤트(`share_click`) | **[Q1 GA 실측 대기]** — 경쟁사 벤치마크 부재로 자체 데이터 축적 후 설정 |

### 측정 배선: GA4 크로스도메인 · UTM 규약 · metric_event 경계

- **GA4 크로스도메인**: 놀이터(서브도메인)와 쇼핑몰(nutti.co.kr)은 사용자에게 하나의 브랜드로 읽히므로, 하나의 GA4 속성에 두 도메인을 cross-domain measurement로 연결한다(도메인 전환 시 세션이 끊기지 않도록). 계산기(`calculator.html`)에는 이미 `js/ga.js`가 붙어 있어 같은 속성에 편입한다.
- **UTM 규약**: 놀이터 → 쇼핑몰/계산기로 나가는 모든 아웃바운드 링크에 `utm_source=nutti_playground&utm_medium=referral&utm_campaign=<맥락>`을 부착한다(예: `result_exit`, `calculator_handoff`). 상세 파라미터 표는 06-architecture-deployment에서 확정한다.
- **metric_event 경계**: GA4는 마케팅 기여·크로스도메인 세션 측정을 담당하는 외부 표준 도구다. `metric_event`는 제품 내부 로그(스타일 선택·생성 완료·공유 클릭·출구 클릭 등)로 W-11 운영 콘솔의 스타일별 성과(선택률·공유율·쇼핑몰 클릭률) 산출에 쓰인다. 두 시스템이 같은 사용자 행동에 대해 각자 이벤트를 낼 수 있으나 소유 시스템과 보존 기간(GA4=구글 정책, metric_event=90일)이 다르다. 상세 스키마는 04-erd, 배선 절차는 06-architecture-deployment.

## 7. MVP 범위

- 스코프 ON 6항목(§2) 전부 포함. OFF 4항목은 명시적 비범위.
- **완료 알림(W-05) 제외**: URL 보존 + 재방문 시 복원으로 대체. 근거: `07-decisions.md#Q7`.
- 커스텀 프롬프트(W-08)는 별도 진입점으로 포함하되 기본 카탈로그에서는 숨김(§5 원칙4).
- 운영 콘솔(W-11)은 MVP 범위에 포함 — 프롬프트가 자산이므로 코드 배포 없이 스타일 관리가 필요.
